# Work

Real systems, live in production. Case studies where every fact is taken from the actual work.

- **[Automating a ~600-person care provider, one governed workstream at a time](https://automancer.uk/work/care-provider-transformation/)** (Social care / supported living · Live production pilot) — We are replacing spreadsheets and disconnected tools across a multi-branch supported-living provider with ~18 staged projects. The core system imported 294 carer records and 588 supervision schedules from messy CSVs.
- **[A £300–400 consultant job, done for £10–80 in minutes](https://automancer.uk/work/debiaser-ai-product/)** (Professional services / DEI consulting · Live in production) — For a diversity & inclusion consultancy, we turned a manual document-review service into a live self-service AI product. Same review standard, £10–80 per document, in production since June 2026.
- **[Order-to-dispatch for a UK plastics manufacturer](https://automancer.uk/work/manufacturer-trade-portal/)** (Manufacturing / building-products trade supply · Phase 1 signed off) — We replaced phone-and-memory order taking with a trade portal covering customer pricing, catalogue, orders, production, and dispatch in one flow. Phase 1 signed off.
- **[From zero to live, in days, for near-zero running cost](https://automancer.uk/work/fast-small-business-websites/)** (Small business / web · Live) — Fast, affordable landing sites for small businesses that need a credible website quickly, with no monthly platform fees.

Each case study is also available as clean Markdown at its URL plus `.md`.
